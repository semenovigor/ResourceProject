ПЛАНИРОВКА БАНИ 8,0 × 5,0 м (40 м²)
=====================================

Заданные условия:
- Габарит здания: 8 × 5 м
- Парилка: 2,8 × 2,8 м
- Обязательно: комната отдыха, душевая/моечная

Схема (вид сверху, вход снизу):

    0м        1,2       4,0              5,2              8,0
    ┌─────────┬─────────────────────────────────────────────┐
 5м │   С/У   │           КОМНАТА ОТДЫХА                    │
    │1,2×1,4  │           диван / стол / отдых              │
    │         │                                             │
    ├─────────┤              15,6 м² (чистая)               ├──────────────┐
    │         │                                             │ ДУШ  │ПАРИЛКА│
    │         │                                             │1,2×  │2,8×2,8│
    │         │                                             │2,8   │ 7,8м² │
 2,2├─────────┴───────────────┬─────────────────────────────┼──────┴───────┤
    │        ТАМБУР           │                             │              │
    │        1,5 × 1,8        │     МОЕЧНАЯ / ДУШЕВАЯ       │   полки+печь │
    │         + вход          │        4,0 × 2,2 м          │              │
 0м └─────────────────────────┴─────────────────────────────┴──────────────┘
              ВХОД ↑

Маршрут: улица → тамбур → комната отдыха → моечная/душ → парилка

Помещения:
1. Парилка ............ 2,8 × 2,8 м = 7,8 м²
2. Моечная/душевая .... 12,2 м² (зона 4,0×2,2 + проход-душ 1,2×2,8)
3. Комната отдыха ..... ~15,6 м² (+ тамбур 2,7 + с/у 1,7 в левом блоке 20 м²)
4. Тамбур ............. 1,5 × 1,8 м
5. Санузел ............ 1,2 × 1,4 м

Решения:
- Парилка в дальнем углу — меньше теплопотери
- Топка печи из комнаты отдыха
- Два уровня полок вдоль стены
- Высота парной 2,1–2,3 м; комнаты отдыха 2,4–2,7 м
