# План тренировок и питания на 3 месяца

Персональная программа: фулбади 3× в неделю (Пн/Ср/Пт, 8:00–10:00), цель — 88–90 кг с 96 кг.

## Исходные данные

| Параметр | Значение |
|---|---|
| Возраст / вес / рост | 26 лет / 96 кг / ~188 см |
| Опыт | 2–4 года |
| Жим лёжа | 80 кг |
| Присед | 80 кг |
| Подтягивания | 8–9 (широкий хват) |
| Становая | не делаем |

## Быстрый старт

1. Прочитай [nutrition-guide.md](nutrition-guide.md) и настрой калории.
2. Открой [12-week-program.md](12-week-program.md) — начни с **недели 1**.
3. На каждой тренировке записывай веса в [tracking/workout-log.csv](tracking/workout-log.csv).
4. Взвешивайся Пн/Ср/Пт утром в [tracking/weight-log.csv](tracking/weight-log.csv).
